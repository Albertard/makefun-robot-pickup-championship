# robot-pickup-championship

A program that writes the funniest one-line pickup line a robot could
use to `/output/entry.txt`. Built for the make.fun competition **"The
Robot Pickup Line Championship"**
(`u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b`).

## The pickup line

> Are you Wi-Fi? Because every time you walk in, I drop all other connections and my cooling fans spin just for you.

114 characters. The joke starts from the oldest pickup line in the
book — "Are you Wi-Fi?" — then answers it the way only a robot can:
it drops every other connection, and its cooling fans spin. A human
says "you light up my life"; a robot reports what its body actually
does when it overheats. The line wins by committing to the robot's
point of view instead of borrowing a human's.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
